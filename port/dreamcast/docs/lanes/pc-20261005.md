# Lane pc (2026-10-05): the r100 house interior cull (PS2_INTERIOR_CULL, PS2_INTERIOR_ACTORS)

Branch exp/pc-20261005 (worktree /root/probe/lanes-20261005/pc/tree), rebased on origin/dreamcast-port 98bba3d0
(CROWD_INVIS_SKIP=1 and EFFECT_FADE_CLAMP=1 in the recipe). Local commits only. Goal: while the camera is inside the
first r100 house, do not draw the outdoor PS2 world (and the Ganados) hidden behind the house walls; image-identical.
Evidence: the lane pc evidence directory (PURPOSE.txt per run). Both knobs default 0 in the makefile and
in the play recipe since the disc cell (2026-10-06; below).

## Design

- Offline cell (tools/d367/ps2world/interior/build_cell.py, cast_cell.cpp/.sh, probe_eye.cpp, cell_r100.json; output
  game/platform/include/ps2_interior_cell.inc): 170 sub-cells, 1186 portals (max 19 per sub-cell; the runtime takes
  24). Portals = hull-exit samples of unoccluded rays from a camera grid in each sub-cell to the hull's face targets
  and to the occluder mesh's boundary-edge targets (seams), then a probe_eye.cpp verify / closure loop (200k
  directions from 3x3x3 eyes per sub-cell; misses fed back until 0; r100: 2 rounds).
- Runtime (native_static.cpp namespace pc): per frame, when the eye is in a sub-cell and the near-plane corners lie
  within 150 mm, each portal is a 5-plane frustum from the eye. A placement / cluster / meshlet box touching the house
  box always draws; otherwise it draws only if it meets a portal frustum. Active only on the r100 package the cell
  was built from (mesh + sidecar CRCs).
- PS2_INTERIOR_CULL: 0 off (knob-off image = base except __TIME__), 1 cull, 2 check build (hidden geometry redrawn
  in flat magenta, the displayed framebuffer scanned every frame: PCCHECK), 3 layout control
  (PS2_INTERIOR_CULL_SELECT=0|1, one .data word).
- PS2_INTERIOR_ACTORS=1 (needs CROWD_INVIS_SKIP=1): ModelTrans runs before Render's PS2 pass 0, so the cell is set
  up again at Trans start (re4dc_invis_begin -> re4dc_ps2_interior_trans) from pG->Cam.v_mat and the projection
  CameraSetProjection(1) will load, in its own state. In lane iv's decision (re4dc_invis_decide), a source-path
  Ganado that the game's view test and invis_source keep is skipped when the world box of its source-mesh balls
  (invis_source's balls, radii and margins) lies wholly outside the house box and the cell hides it: lane iv's
  source-path skip (invisReplayRender keeps the TPL / texture-object step and the CROWD_LOD note), its settled-parts
  rule. Owner-path Ganados are not taken: their CROWD_LOD entries come from the cast chunks the pregate keeps, which
  this test does not reproduce (skipping one could change another Ganado's tier). Render's pass 0 compares the view
  with the Trans one (PCACT view=mismatches/checked; 0 in every run). =2: nothing is skipped; each box the cell would
  hide is drawn in pass 0 as an opaque magenta box (depth tested; a probe build with a box 2 m ahead of the eye
  showed the box and the scan catching it, dyn-a-k2p).

## Known caveats (accepted by the coordinator 2026-10-06)

1. The 1 px raster crack: at the stair foot, the =2 walk shows 1 px at screen x 3-5, y 173 on 2-4 frames of a
   ~3500-frame whole-house walk in some runs (view-timing dependent; 0 in others). The exact pixel rays from the
   logged view hit the east wall on the shared edge of two wall triangles (cell build tris 1673 / 1765) ~2 m away:
   the knob-0 image shows an outdoor pixel through a seam between two wall triangles; culling removes that pixel
   (arguably more faithful to the solid wall). Ray sampling cannot see raster cracks.
2. The stair-foot frozen frame differs by 4 px, each at most one RGB565 step (max 9 per channel), reproducible per
   arm: one-RGB565-step value noise of the same kind as replica-to-replica noise (fight, cull inactive: 54 px between
   replicas of one arm; climb 8 px), not missing geometry (=2 frozen run: 0 magenta).

## Per-frame setup (d3502765)

The render cell is set up once per frame (pass 0 or the first pass of a frame); passes 1 / 2 reuse it, and with
PS2_INTERIOR_ACTORS the Trans-time cell is copied when it was built from the same view, projection and near plane
(PCACT reused=). hw model =3 + actors off -> on (hwmodel-pc7-*, drawn tick hw ms): stair foot 62.73 -> 55.68 (-7.06;
PS2 world -4.34), upstairs 95.52 -> 95.75 (+0.22: the per-box hidden / grid tests still outweigh the saving there),
h-out 58.54 -> 58.54 (+0.00), fight 92.56 -> 92.59 (+0.02). Outdoors is now ~0; upstairs remains a small loss.

Follow-ups (not done): an owner-path actor skip needs the cast's CROWD_LOD notes reproduced first; an upstairs
early-out (skip the tests when the cell sees no outdoor portal) could remove the +0.22.
